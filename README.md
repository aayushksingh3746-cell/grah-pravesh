# Chandel Family Royal Invitation

Static, mobile-first bilingual invitation website. Includes the supplied entrance photograph, animated door intro, English/Hindi toggle, invitation folio, two-day schedule, date-only countdown, all-day `.ics` download, copy-address, native sharing, and interactive family-memory panels.

## Deploy to Vercel
- Framework preset: **Other**
- Build command: leave blank
- Install command: leave blank
- Output directory: `.`
- No package.json, build step, database or backend is required.

## Before publishing
The RSVP area intentionally remains a contact-details placeholder. Add verified call and WhatsApp links only after confirming the family's preferred contact number. Do not publish an unverified number.

The calendar contains two all-day events for 10 and 11 March 2027 because exact ceremony times have not been provided. No maps or directions links are included. Canonical/share URL: https://chandel-grah-pravesh-five.vercel.app/
